# 2. De la imprenta a la era digital

La idea de marcar un texto es anterior a los ordenadores. Lo que cambia es quién interpreta las marcas y cómo se comparten los documentos.

## Las anotaciones de imprenta

Los editores anotaban los manuscritos para indicar a los tipógrafos dónde colocar un título, qué tipo de letra utilizar o cómo alinear un párrafo. Las marcas orientaban la preparación del texto impreso.

## Los primeros formatos digitales

Cade programa podía guardar los documentos con sus propias convenciones. Intercambiar un archivo entre aplicaciones podía provocar incompatibilidades o pérdida de formato. Hacían falta formas comunes de representar la estructura.

## SGML: una base general

En los años ochenta se estandarizó **SGML**, siglas de *Standard Generalized Markup Language*. Permitía definir lenguajes de marcado para documentos estructurados. Su flexibilidad también implicaba complejidad.

## HTML y XML

- **HTML** nació en el contexto de la Web para estructurar documentos enlazados. Sus primeras versiones se apoyaban en SGML.
- **XML** surgió como una simplificación de SGML orientada a describir e intercambiar información estructurada.

!!! note "Una relación histórica"
    Esta herencia no significa que HTML y XML sean intercambiables. El HTML moderno tiene sus propias reglas de análisis y XML exige una sintaxis bien formada.

## Un ecosistema diverso

Junto a HTML y XML existen lenguajes como **Markdown**, centrado en la facilidad de escritura, **Wikitext**, empleado en wikis, y **LaTeX**, utilizado para preparar documentos, especialmente técnicos y científicos.

La evolución no consiste en que un lenguaje sustituya a todos los anteriores: cada uno responde a necesidades distintas.
