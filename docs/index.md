# Lenguajes de Marcas y Sistemas de Gestión de la Información

Bienvenido al espacio del módulo de **Lenguajes de Marcas y Sistemas de Gestión de la Información (LMSGI)**.

En este sitio encontrarás apuntes, actividades, ejemplos y recursos para aprender a trabajar con lenguajes de marcas, XML y las tecnologías utilizadas para estructurar, validar y transformar información.

## Secuencia de aprendizaje

!!! note "Itinerario del módulo"
    Lenguajes de marcas → XML → Validación con DTD → Validación con XSD → Consulta con XPath → Transformación con XSLT

## Cómo utilizar este sitio

!!! tip "Recomendación"
    Sigue las unidades en el orden propuesto. Los contenidos son progresivos y cada unidad se apoya en los conocimientos adquiridos en las anteriores.

!!! info "Consejos de estudio"
    - Lee los contenidos antes de realizar las actividades.
    - Practica todos los ejemplos propuestos.
    - Valida tus documentos XML frecuentemente.
    - Comprueba los errores utilizando las herramientas recomendadas.
    - Utiliza el menú lateral para navegar por los distintos apartados.
