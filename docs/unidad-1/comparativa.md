# 5. Comparativa rápida

## Cuatro lenguajes, cuatro enfoques

| Característica | HTML | XML | Markdown | Wikitext |
| --- | --- | --- | --- | --- |
| Propósito | Estructurar páginas web. | Describir e intercambiar datos. | Escribir documentos con marcado sencillo. | Crear páginas de una wiki. |
| Marcas | Elementos definidos por el estándar. | Etiquetas definidas para los datos. | Símbolos como `#`, `*` y `-`. | Símbolos como `[[ ]]`, apóstrofos y `==`. |
| Aprendizaje inicial | Intermedio. | Sintaxis estricta; complejidad según el formato. | Sencillo. | Sencillo al inicio; ampliable con plantillas. |
| Ejemplo de uso | Página de un blog. | Factura electrónica. | Archivo `README.md`. | Artículo de Wikipedia. |

## ¿Cuál utilizarías?

- **Una página web:** HTML aporta la estructura que interpreta el navegador.
- **Un pedido que debe leer otra aplicación:** XML permite describir sus datos mediante etiquetas acordadas.
- **Unos apuntes fáciles de editar:** Markdown mantiene el texto legible y admite conversión a otros formatos.
- **Una enciclopedia dentro de MediaWiki:** Wikitext facilita los enlaces internos y las plantillas.

!!! tip "No siempre hay que elegir solo uno"
    Un proyecto puede utilizar Markdown para sus documentos, generar HTML para la web e intercambiar información mediante XML.

4. Por qué `#` no significa lo mismo en Markdown y en Wikitext.
