# Unidad 2 · XML y documentos bien formados

## Estructurar datos para compartir información

En la unidad anterior aprendiste que los lenguajes de marcas permiten describir la estructura y el significado de un documento.

XML da un paso más: permite crear nuestras propias etiquetas para representar información de cualquier tipo. Gracias a ello puede utilizarse para almacenar datos, intercambiar información entre aplicaciones o describir documentos de forma estructurada.

En este tema conocerás qué es XML, cómo se diferencia de HTML y cuáles son las reglas que debe cumplir un documento para considerarse correctamente construido.
