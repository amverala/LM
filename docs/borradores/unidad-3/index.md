# Unidad 3 · Validación XML y DTD

## Garantizar la estructura y calidad de los datos

En la unidad anterior aprendiste a crear documentos XML correctamente formados siguiendo las reglas sintácticas del lenguaje.

Sin embargo, que un documento XML esté bien formado no significa necesariamente que tenga la estructura adecuada para una aplicación real. Cuando intercambiamos información entre sistemas es necesario garantizar que los datos cumplen unas reglas concretas.

En esta unidad aprenderás a validar documentos XML utilizando DTD (*Document Type Definition*), definiendo elementos, atributos y restricciones que permitan comprobar automáticamente si un documento es correcto.
