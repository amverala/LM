# Unidad 5 · XPath y XSLT

## Acceso y transformación de documentos XML

En las unidades anteriores aprendiste a crear documentos XML bien formados y a validarlos mediante DTD y XML Schema (XSD), garantizando que la información almacenada cumple una estructura determinada.

Una vez que los datos están correctamente organizados y validados surge una nueva necesidad: acceder únicamente a la información que nos interesa y transformarla para presentarla en distintos formatos.

Para resolver estos problemas existen dos tecnologías fundamentales del ecosistema XML:

- XPath, que permite localizar elementos, atributos y contenidos dentro de un documento XML.
- XSLT, que permite transformar documentos XML en otros formatos como HTML, XML o texto plano.

Estas tecnologías son ampliamente utilizadas en aplicaciones de integración de datos, intercambio de información entre sistemas, generación automática de documentos y publicación de contenidos web.

En esta unidad aprenderás a consultar documentos XML utilizando expresiones XPath y a construir transformaciones XSLT capaces de generar páginas HTML de forma automática.
